📚 app-brosur v1

Aplikasi web sederhana untuk pencarian dalil berbasis teks terjemah Indonesia dengan fitur highlight kata kunci dan navigasi hasil.

🎯 Tujuan Aplikasi

Memudahkan pencarian dalil berdasarkan kata atau konteks

Menampilkan potongan relevan (snippet)

Menyediakan tampilan dalil lengkap (Arab + terjemah) melalui HTML asli

Fokus cepat, ringan, dan praktis

🚀 Fitur Utama v1
🔍 Pencarian

Search berbasis isi terjemah Indonesia

Mendukung multi-kata

Ranking relevansi + snippet kontekstual

✨ Highlight di Halaman Detail

Semua keyword ter-highlight

🔢 Counter highlight (contoh: 3 / 12)

⬆⬇ Navigasi Next / Prev

🟡 Highlight aktif berwarna hijau stabilo

Scroll otomatis ke keyword aktif

🧼 UX Bersih

Tombol Next / Prev tidak muncul sebelum pencarian

Navigasi highlight hanya aktif saat detail terbuka
